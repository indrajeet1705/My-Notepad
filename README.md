# My Notepad

## 📌 Overview
**My Notepad** is a simple and lightweight web-based note-taking application built using React and Redux Toolkit. It allows users to create, edit, and manage their notes efficiently with a seamless and intuitive user interface.

## 🔥 Features
- **Create and Edit Notes** – Quickly add and modify notes.
- **Auto-Save Functionality** – Ensures notes are not lost.
- **Dark Mode Support** – User-friendly theme selection.
- **State Management with Redux Toolkit** – Efficient global state management.
- **Download Notes** – Export your notes for offline access.
- **Responsive UI** – Works smoothly on desktop and mobile devices.

## 🛠️ Technologies Used
- **Frontend:** React, Redux Toolkit
- **Styling:** Tailwindcss
- **State Management:** Redux Toolkit
- **Deployment:** GitHub Pages

## 🚀 Getting Started
### Prerequisites
- Node.js and npm installed
- A web browser (Chrome, Firefox, Edge, etc.)

### Installation & Setup
1. **Clone the repository:**
   ```bash
   git clone https://github.com/indrajeet1705/My-Notepad.git
   cd My-Notepad
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Run the application:**
   ```bash
   npm start
   ```
4. **Open in Browser:**
   Navigate to `http://localhost:3000`
